# Nuzran Nazeer - Developer Portfolio

A responsive React portfolio with an interactive CSS 3D sculpture, project details, education, CV download, and contact links. Built with React, Vite, and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

Use `npm.cmd` on Windows if PowerShell blocks `npm.ps1`.

## Checks and production build

```sh
npm run lint
npm run build
npm run preview
```

Deploy the `dist` directory to a static host.

## Update content

- `src/portfolio.js`: profile, skills, education, project descriptions, and links. PDT's live link is configured; add other live and repository links when available.
- `src/App.jsx`: page structure and interactions.
- `src/index.css`: styling, responsive layouts, and motion.
- `public/nuzran-nazeer-cv.pdf`: downloadable CV.
- `index.html`: page title and search description.

Project artwork is abstract illustration. Motion supports pause and reduced-motion preferences. Contact uses email and social links.
